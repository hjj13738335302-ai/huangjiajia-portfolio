# 标题与关于我图片调整设计说明

## 背景与目标

用户希望将创作宣言、关于我、精选作品、核心能力四个区块的大标题缩小一级，并把中文标题稳定为两行；同时将“关于我”右侧竖幅图替换为用户提供的猫咪采访画面。

## 现状与约束

- 四个标题都由 `aigc-portfolio-content.js` 在页面加载后重写，但当前仅通过 `<br>` 分隔两段，强调段仍会因字号过大再次换行。
- 基础字号来自打包后的 CSS；新增样式继续放在 `aigc-portfolio-overrides.css`，避免修改压缩产物。
- 小号英文副标题保留，不计入用户所说的两行中文大标题。
- 保留现有黑白红视觉体系、动效、段落与视频内容。

## 方案对比

### 方案一：只缩小现有字号

- 优点：改动最少。
- 缺点：不同窗口宽度下强调段仍可能自动换成第三行。

### 方案二：两行标题组件 + 响应式字号（采用）

- 优点：两段中文分别成为独立行，桌面与手机都可精确控制；四个区块样式一致。
- 缺点：需要同时调整标题 HTML 结构与 CSS。

### 方案三：缩短中文标题文案

- 优点：最容易控制行数。
- 缺点：改变用户已经确认的文案表达，不符合本次“缩小字号”的要求。

## 详细设计

### 标题结构

将四个区块标题统一为两个 `.section-title__line` 元素，第二行继续使用 `<i>` 保留强调色。英文 `<small>` 独立位于两行中文标题下方。

### 标题尺寸

在覆盖样式中为四个区块增加统一的响应式标题规则；“关于我”因左右分栏较窄，使用略小的上限。每个中文行都使用 `white-space: nowrap`，并在桌面与手机断点分别控制字号，确保不产生第三行或横向溢出。

### 关于我图片

把 `F:\0-黄佳佳\26.10.16\镜头图片\镜头2.png` 转为网页用 WebP，保存为 `about-cat-interview.webp`。图片继续使用现有 `object-fit: cover` 填充竖幅容器，并更新为准确的替代文本。

### 测试策略

- 合同检查确认两行标题结构、新图片声明与文件存在。
- 浏览器检查桌面端和手机端的四个标题均恰好包含两条中文标题行、无横向溢出。
- 检查新图片已加载且尺寸有效，同时复验 4 个 TVC、4 个 UGC 和首个视频播放。

## 风险与边界

- 极窄屏幕下长标题需要明显缩小，因此手机字号单独控制。
- 不修改首页主标题、轮播图、作品文案或视频内容。
