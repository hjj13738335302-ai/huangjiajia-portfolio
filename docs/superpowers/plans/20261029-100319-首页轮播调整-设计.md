# 首页文案与作品轮播调整设计说明

## 背景与目标

新版作品集已经以 AIGC 视频作品为主体，但首页首屏仍保留旧的“产品 / 空间 / 视觉叙事”定位与旧中文介绍，第二屏轮播使用的是视频封面。此次调整要让首屏定位与 AIGC 求职方向一致，并用用户提供的 10 张静态作品图展示更完整的产品视觉能力。

## 已确认方案

- 首页英文大标题、背景图、导航与交互动效保持不变。
- 标题上方小字改为：`AIGC / 产品 / 视觉叙事`。
- 中文标语改为：`我以 AIGC 为核心，把产品卖点转化为能被看见、理解与记住的视觉内容。`
- 第二屏继续使用现有双排错位横向移动结构。
- 上排优先展示完整产品、家居场景和多款式画面；下排优先展示使用视角、开口结构、俯视细节和猫咪互动。
- 10 张 PNG 转换为 WebP，最长边控制在 1600 像素以内，在不明显损失观感的前提下降低加载体积。

## 实现边界

- 不修改压缩后的原始 React 打包文件。
- 在现有 `aigc-portfolio-content.js` 内容覆盖层中增加首页文案更新，并替换轮播数据源。
- 不改变 TVC、UGC、能力介绍、个人介绍与页脚结构。

## 验收标准

- 桌面端与手机端都显示新的首页小字和中文标语。
- 第二屏只使用新提供的 10 张图片，不再出现视频封面。
- 两排图片均持续保留原有错位移动效果，页面无横向溢出。
- 新图片均可从 GitHub Pages 正常加载，首个 TVC 仍可播放。
